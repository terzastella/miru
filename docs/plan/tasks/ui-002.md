# ui-002 — Port del design system dal prototipo HTML v0

## Obiettivo
Rendere l'app MIRU "simile a" il prototipo single-file HTML fornito dall'utente
(reference: font Bebas Neue + Inter, palette `#0c0c10`/`#ff5a2c`/`#36d1c4`,
header sticky con logo 見 + tab pill, stamp, ribbon, righe orizzontali, badge
fonte, banner cooldown, dialogo "Aggiungi anime", pagina Consigliati).

## Vincoli rispettati
- Resta l'architettura server-side: nessuna chiamata diretta a `api.jikan.moe`
  dal client (spec §3/§6) — a differenza del prototipo, che chiamava Jikan dal browser.
- Restano i18n it/en (spec §15): tutte le stringhe passano da `lib/i18n.tsx`.
- Resta l'a11y: skip-link, focus-visible accent, `prefers-reduced-motion` kill-switch
  (spec §14).

## Modifiche
- `app/globals.css` riscritto: token `--background:#0c0c10`, `--primary:#ff5a2c`,
  `--accent-2:#36d1c4`, `--heart:#ff3f6e`, `--stamp:#d92b4b`, `--surface/#1b1b24`,
  `--surface-2/#23232e`, radius 16px; body con radial-gradient; nuovi token colore

  utilities `@utility`: `stamp`, `fav-ribbon`, `cw-row` (righe orizzontali con

- `lib/i18n.tsx` — nuove chiavi it/en: `nav.recommend`, `nav.add`, `stamp.done/
  onhold/dropped`, `home.addFirst`, `home.seeAll`, `add.*`, `recommend.*`.
- `lib/store.tsx` — nuovo stato UI `addOpen/openAddDialog/closeAddDialog` (stesso
  pattern di `detailId`) per il dialogo globale di aggiunta.

  debounce 450ms su `/api/anime/search`, lista con poster/meta, bottone "+ Aggiungi",
