Prima release pubblica di MIRU: diario anime per Windows.

## Cosa c'è

- Libreria con stati, preferiti, voto personale, note, tag e contatore rewatch
- Progresso episodi con "segna tutti" e paginazione per serie lunghe
- Consigliati per genere, Esplora con filtri, ricerca con aggiunta rapida
- Export/import JSON ed export XML compatibile MyAnimeList
- Catalogo locale precaricato (~1200 titoli) al primo avvio, ricerca istantanea
- Interfaccia IT/EN, lingua presa dal sistema al primo avvio

## Requisiti

- Windows 10/11 con WebView2 Runtime (già presente su Windows 11)
- Nessuna installazione, nessun Node.js: `MIRU.exe` è un singolo file portabile

## Installazione

1. Scarica `MIRU.exe` dagli asset qui sotto
2. Avvialo da dove preferisci: i dati restano in `%LOCALAPPDATA%\app.miru.desktop`
