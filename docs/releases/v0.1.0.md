## 🇮🇹 Italiano

**MIRU** è un diario anime per Windows: la tua libreria, i tuoi episodi, i tuoi voti — tutto sul tuo PC.

### Cosa c'è

- **Libreria** con stati (da vedere, in corso, in pausa, completati, droppati), preferiti, voto personale, note, tag e contatore rewatch
- **Progresso episodi** casella per casella, con "segna tutti" e paginazione per le serie lunghe
- **Consigliati** calcolati dai generi che segui davvero, con "non mi interessa"
- **Esplora** con filtri per tipo, stato, anno, episodi, studio, generi e voto minimo
- **Export/import** JSON ed export XML compatibile MyAnimeList
- **Catalogo locale** precaricato (~1200 titoli) al primo avvio: ricerca e consigliati istantanei
- **Interfaccia IT/EN**, lingua presa dal sistema al primo avvio

### Requisiti

| | |
|---|---|
| Sistema | Windows 10 / 11 (x64) |
| Runtime | WebView2 (già presente su Windows 11) |
| Installazione | nessuna: un solo file portabile |

### Installazione

1. Scarica [**MIRU.exe**](https://github.com/terzastella/miru/releases/download/v0.1.0/MIRU.exe) (14.7 MB)
2. Mettilo dove preferisci e avvialo: i dati restano in `%LOCALAPPDATA%\app.miru.desktop`

### Integrità

SHA-256, verificabile con `Get-FileHash .\MIRU.exe -Algorithm SHA256`:

```
B35688AE7D9AFF8B825A084DC9667CCDA960F6980C68000937B1CDDA65BD52F6
```

### Note

- Eseguibile **non firmato**: SmartScreen può chiedere conferma ("Ulteriori informazioni" → "Esegui comunque")
- Catalogo = i ~1200 titoli più popolari e più votati, non l'intero database AniList
- Se Jikan non risponde, ricerca e dettaglio passano ad AniList (~7 s il primo tentativo)

## 🇬🇧 English

**MIRU** is an anime diary for Windows: your library, your episodes, your scores — all on your machine.

### What's inside

- **Library** with statuses (plan to watch, watching, on hold, completed, dropped), favourites, personal score, notes, tags and a rewatch counter
- **Episode progress** checkbox by checkbox, with "mark all" and pagination for long series
- **Recommendations** derived from the genres you actually follow, with "not interested"
- **Explore** with filters by type, status, year, episodes, studio, genres and minimum score
- **Export/import** JSON plus MyAnimeList-compatible XML export
- **Local catalog** prefetched (~1200 titles) on first launch: instant search and recommendations
- **English / Italian UI**, language taken from your system on first launch

### Requirements

| | |
|---|---|
| System | Windows 10 / 11 (x64) |
| Runtime | WebView2 (preinstalled on Windows 11) |
| Install | none: a single portable file |

### Install

1. Download [**MIRU.exe**](https://github.com/terzastella/miru/releases/download/v0.1.0/MIRU.exe) (14.7 MB)
2. Put it anywhere and run it: your data stays in `%LOCALAPPDATA%\app.miru.desktop`

### Integrity

SHA-256, check with `Get-FileHash .\MIRU.exe -Algorithm SHA256`:

```
B35688AE7D9AFF8B825A084DC9667CCDA960F6980C68000937B1CDDA65BD52F6
```

### Notes

- The executable is **unsigned**: SmartScreen may ask for confirmation ("More info" → "Run anyway")
- Catalog = the ~1200 most popular and top-rated titles, not the whole AniList database
- If Jikan doesn't answer, search and details fall back to AniList (~7 s on the first attempt)
