## 🇮🇹 Italiano

**MIRU 0.1.1** è una release di consolidamento: nessuna nuova funzione, più affidabilità sui dati che hai già.

### Cosa cambia

- **Validazione dei dati locali**: se il salvataggio contiene un JSON valido ma con tipi sbagliati, i campi vengono normalizzati (episodi, tag, preferenze) invece di far crollare l'app. Se la struttura è inutilizzabile, il file viene messo in quarantena in `miru.state.v1.corrupted.<timestamp>` e non viene più sovrascritto.
- **Backup più sicuri**: l'import valida ogni voce prima del merge; le voci rotte vengono scartate singolarmente, il resto entra.
- **Date**: test dedicato al fuso `Europe/Rome` — a mezzanotte e mezza la data resta corretta anche dove UTC arretrerebbe di un giorno.
- **CI**: nuovo job su Windows che compila davvero l'eseguibile Tauri, calcola lo SHA-256 e lo allega come artefatto (parte sui tag e su richiesta manuale).

### Installazione

1. Scarica [**MIRU.exe**](https://github.com/terzastella/miru/releases/download/v0.1.1/MIRU.exe) (14.7 MB)
2. Mettilo dove preferisci e avvialo: i dati restano in `%LOCALAPPDATA%\app.miru.desktop`

Requisiti invariati: Windows 10/11 con WebView2 Runtime, nessuna installazione, nessun Node.js.

## 🇬🇧 English

**MIRU 0.1.1** is a consolidation release: no new features, just more reliable handling of the data you already have.

### What changed

- **Local data validation**: if the saved state is valid JSON with wrong types, fields are normalised (episodes, tags, preferences) instead of breaking the app. If the structure is unusable, the blob is quarantined to `miru.state.v1.corrupted.<timestamp>` and never silently overwritten.
- **Safer backups**: imports validate every entry before merging; broken entries are skipped individually, the rest gets in.
- **Dates**: dedicated test for the `Europe/Rome` timezone — at 00:30 the local date stays correct where UTC would slip a day back.
- **CI**: new Windows job that actually builds the Tauri executable, computes its SHA-256 and uploads it as an artifact (runs on tags and manual dispatch).

### Install

1. Download [**MIRU.exe**](https://github.com/terzastella/miru/releases/download/v0.1.1/MIRU.exe) (14.7 MB)
2. Put it anywhere and run it: your data stays in `%LOCALAPPDATA%\app.miru.desktop`

Requirements unchanged: Windows 10/11 with WebView2 Runtime, no installer, no Node.js.

### Integrity

SHA-256, check with `Get-FileHash .\MIRU.exe -Algorithm SHA256`:

```
3CBC6F3734CD5AC00F5F3EBCEAD4F2D54FE840A38F596314806BC5252358B7A6
```

### Notes

- Upgrade over 0.1.0: same data folder, library and catalog are preserved.
- The executable is unsigned: SmartScreen may ask for confirmation ("More info" → "Run anyway").
